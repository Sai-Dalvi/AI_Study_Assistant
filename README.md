# 🤖 AI Study Assistant

An AI-powered web application that helps college students learn concepts, ask questions, generate study summaries, and practice with MCQs.

## 🌟 Features

- 🤖 **Ask AI** – Ask questions and get simple AI-generated explanations.
- 📚 **Subject Selection** – Select a subject such as Python, DBMS, DSA, Data Science, or AI.
- 📝 **Study Summary** – Generate short, clear, and exam-friendly study notes.
- ❓ **MCQ Generator** – Generate 5 multiple-choice questions for practice.
- ⚡ **Quick Questions** – Quickly ask common study questions.
- 💬 **Chat History** – View previously asked questions and generated answers.
- 📱 **Responsive Design** – Works on desktop and mobile screens.
- 🔐 **Secure API Key** – API key is stored using environment variables.

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **AI:** Google Gemini API
- **Environment Management:** python-dotenv
- **Development Tool:** Visual Studio Code
